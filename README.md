# Выравнивание последовательностей АМК

## Cтруктура проекта

- `App` - папка с конфигурацией приложения
- `modules` - папка с основным модулем

#### Папка `src/module/*`

- `components` - папка с компонентами, использующимися в модуле
- `types` - перечисление типов, использующихся в модуле
- `utils` - утилиты, использующиеся в модуле
